# Architecture decision records

One file per decision: `NNNN-short-slug.md`, numbered in order, never reused.

## Rules

- Accepted decisions are immutable. To change one, write a new ADR that supersedes it and set the old one to `Status: superseded by NNNN`.
- One decision per file. If you are writing "and also", split it.
- Write it when the decision is made, not months later.
- Keep it short: context, decision, consequences. The alternatives exist so the next person does not relitigate them.

## Template

Copy `0000-template.md` to the next free number.
